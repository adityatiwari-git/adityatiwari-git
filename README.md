## 🚀 Currently Building

### 🧬 GenomeZ — DNA Sequence Analyzer

A Django-based bioinformatics web application for analyzing DNA sequences.

**Features / capabilities:**
- DNA → RNA & RNA → DNA
- Complement & Reverse Complement
- GC Content & ATGC Count
- Protein Translation
- Motif Finder & ORF Finder
- FASTA / TXT sequence uploads
- Analysis reports and downloads
- Analysis history
- Scientific analysis dashboard

**Tech:** `Python` `Django` `HTML` `CSS` `Bootstrap` `MySQL`

### 🏥 Accord-HMS — Hospital Management System

A Django-based hospital management project designed around practical workflows for patients, doctors, departments, appointments, profiles, and administration.

**Tech:** `Python` `Django` `Bootstrap` `SQLite`
